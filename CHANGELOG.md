# Vue PrettyBox Changelog

---

### Version 1.1.0 (27-10-2024)

> - Migrated lightbox transitions to `motion-v` with automatic reduced-motion handling.
> - Added keyboard navigation (Esc, flechas), focus trap y restauración de foco en todos los modales.
> - Creado `useLightboxA11y` y `useReducedMotion` como utilidades compartidas.
> - Añadido tests básicos con Vitest para navegación por teclado y backdrop.
> - Actualizado toolchain a Vue 3.4, Vite 5, TypeScript 5.4 y Vitest 1.6.
> - Documentación actualizada con nuevas capacidades de accesibilidad.

### Version 1.0.0 (28-12-2022)

> - Released

### Version 1.0.0-beta-2 (15-12-2022)

> - All components were redesigned and changed to TypeScript to improve the experience.
> - ProductGallery was added.
> - `animation` prop now is not required.
